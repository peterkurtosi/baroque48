◉

Mielőtt belekezdesz

A BBASIC a BAROQUE 48 saját BASIC-je. Ugyanabban a szellemben készült, mint a gép többi része: kevés dolgot tud, de azokat úgy, ahogy 1983-ban is illett volna. Ez a könyv a nyelvről szól — a parancssort a BAROQUE-DOS Kézikönyv írja le.

A parancsok angolul vannak, mert a gép angolul beszél; a magyarázat magyarul. Amit ilyen betűvel látsz, azt szó szerint így kell begépelni.

Belépés és kilépés

A DOS-promptból a BBASIC paranccsal lépsz be:

BBASIC
BAROQUE BASIC 1.1
49152 BYTES FREE
Ok

A gép kiírja, mennyi hely maradt a programnak, és megjelenik a Ok — ez a BASIC promptja. Kilépni a SYSTEM paranccsal lehet (a BYE is jó):

SYSTEM
C:\>
Jó hír

A gép nem érzékeny a kis- és nagybetűre.

A print és a PRINT ugyanaz. A könyvben a korhűség kedvéért mindenhol nagybetűs alak szerepel.

Az Ok jelentése

Az Ok

kisbetűs, és ez nem elírás: a korabeli gépek pontosan így írták. Azt jelenti, hogy a gép végzett, és vár.

◉

Az első öt perc

A BASIC-nek két üzemmódja van, és ez a legfontosabb dolog, amit meg kell érteni. Sorszám nélkül a gép azonnal végrehajtja, amit beírsz. Sorszámmal eltárolja későbbre.

Azonnal

Írj be egy számolást, és nyomj Entert:

PRINT 2+2
 4
Ok

A PRINT helyett ? is írható — a korabeli gépeken ezt mindenki használta:

? 7*6
 42
Ok

Eltárolva

Ha a sort számmal kezded, a gép nem hajtja végre, hanem megjegyzi. Így születik a program:

NEW
10 PRINT "SZIA!"
20 PRINT "EN VAGYOK A BAROQUE 48."
RUN
SZIA!
EN VAGYOK A BAROQUE 48.
Ok

A LIST megmutatja, mi van a tárban:

LIST
10 PRINT "SZIA!"
20 PRINT "EN VAGYOK A BAROQUE 48."
Ok
A sorszámok közé hagyj helyet

A könyvben minden program

tízesével számoz. Nem véletlen: így később be tudsz szúrni egy 15-ös sort anélkül, hogy az egészet újraírnád. A gép a sorokat mindig sorszám szerint rendezve tartja.

Sor törlése

Írd be a sorszámot egyedül, és a sor eltűnik:

10
LIST
20 PRINT "EN VAGYOK A BAROQUE 48."
Ok

A teljes program törlése: NEW. A változóké: CLEAR.

◉

A PRINT

A PRINT írja ki, amit látni akarsz. Két elválasztója van, és nem mindegy, melyiket használod.

A pontosvessző: közvetlenül egymás után

PRINT 1;2;3
 1  2  3
Ok
Miért két szóköz?

A korabeli BASIC minden szám elé tett egy

helyet az előjelnek, és minden szám után egy záró szóközt. Ezért ad a PRINT 1;2;3 két szóközt a számok közé. Szöveg után nincs záró szóköz — csak szám után.

A vessző: oszlopba

PRINT "EGY","KETTO"
EGY           KETTO
Ok

A vessző a következő oszlophatárig ugrik. Táblázathoz ez kell.

Szöveg

PRINT "HELLO, VILAG!"
HELLO, VILAG!
Ok
Sorvégi pontosvessző

Ha a PRINT végére

pontosvesszőt teszel, a gép nem tör sort. A következő PRINT ugyanabban a sorban folytatja. Ezt használja a ciklusok fejezet is.

◉

Számok

A gép a számokat úgy írja ki, ahogy a korabeli gépek: a pozitív szám elé szóköz kerül, az egészek után nincs tizedespont, és a vezető nullát elhagyja.

PRINT 1/4
 .25
Ok
PRINT 10/2
 5
Ok
PRINT -3.5
-3.5
Ok
A .25 nem elírás

A korabeli BASIC a

0.25-öt .25-ként írta ki. Megtartottuk, mert ez a részlet teszi felismerhetővé.

Műveletek

PRINT 7 \ 2
 3
Ok
PRINT 7 MOD 2
 1
Ok
PRINT 2^10
 1024
Ok

A \ egész-osztás, a MOD a maradék, a ^ a hatvány.

A sorrend, ami meglepetést okoz

PRINT -2^2
-4
Ok
Ez nem hiba

A hatvány erősebb az előjelnél,

ezért a -2^2 értéke -4 és nem 4. A korabeli BASIC is így számolt. Ha a másikat akarod, írj zárójelet: (-2)^2.

Más számrendszerek

PRINT &HFF
 255
Ok
PRINT &B1010
 10
Ok
PRINT &O17
 15
Ok
Bővítés

A &H (tizenhatos) és az

&O (nyolcas) korhű. A &B (kettes) bővítés — a korabeli BASIC nem ismerte.

Függvények

PRINT SQR(144)
 12
Ok
PRINT ABS(-7)
 7
Ok
PRINT INT(3.9)
 3
Ok
PRINT SIN(0)
 0
Ok
PRINT PI
 3.141593
Ok

Van még: SGN FIX COS TAN ATN EXP LOG. A LOG természetes alapú (ln), ahogy a korabeli BASIC-ben. A szögek radiánban mennek.

◉

Változók

A gépnek 26 számos rekesze van: A-tól Z-ig. Egy betű, egy szám.

A = 12
B = 30
PRINT A + B
 42
Ok

A LET is írható elé, de nem kötelező:

LET X = 5
PRINT X * X
 25
Ok
Ami nincs

Hosszabb változónév (SZAM,

A1) nincs, és a gép ezt ki is mondja: SYNTAX ERROR. Tömb (DIM) sincs.

◉

Szövegek

A szöveges változó neve $-ra végződik: A$-tól Z$-ig. Egy szöveg legfeljebb 40 karakter.

A$ = "BAROQUE"
PRINT A$
BAROQUE
Ok

Az A és az A$ két külön rekesz

A = 7
A$ = "HET"
PRINT A
 7
Ok
PRINT A$
HET
Ok
Ez nem hiba, hanem a nyelv lényege

A $ nem dísz:

másik változót jelöl. Az A és az A$ egymástól teljesen függetlenek.

Összefűzés

N$ = "PETER"
PRINT "SZIA, " + N$ + "!"
SZIA, PETER!
Ok

Darabolás

PRINT LEFT$("BAROQUE",3)
BAR
Ok
PRINT RIGHT$("BAROQUE",3)
QUE
Ok
PRINT MID$("BAROQUE",2,4)
AROQ
Ok
A MID$ egytől indexel

A

MID$("BAROQUE",2,4) a 2. karaktertől ad 4 darabot. A korabeli BASIC egytől számolt, nem nullától.

Szám és szöveg között

PRINT CHR$(65)
A
Ok
PRINT "N=" + STR$(42)
N= 42
Ok

A CHR$(n) kódból karaktert csinál, a STR$(n) számból szöveget.

Vissza a számok felé

Ez a három függvény szöveget kér, és számot ad:

PRINT LEN("BAROQUE")
 7
Ok
PRINT ASC("A")
 65
Ok
PRINT VAL("42")
 42
Ok
PRINT VAL("12ALMA")
 12
Ok
PRINT VAL("ALMA")
 0
Ok
A VAL nem válogatós

A VAL a szöveg

elejéről olvas számot, és ami utána jön, azt elhagyja. Ezért a VAL("12ALMA") értéke 12, a VAL("ALMA") pedig 0. A korabeli BASIC is így viselkedett.

És együtt

A$ = "BAROQUE 48"
PRINT LEFT$(A$, LEN(A$) - 3)
BAROQUE
Ok
PRINT CHR$(ASC("A") + 1)
B
Ok
Ez többet mond, mint amennyinek látszik

A

LEFT$(A$, LEN(A$) - 3) sorban a szöveges kiértékelő hívja a számosat, az pedig vissza a szövegeset. Ez a gépben a legkényesebb pont, és megmérve működik.

◉

Döntés

Az IF … THEN a nyelv legfontosabb szerkezete. Ha a feltétel igaz, a THEN utáni rész lefut; ha hamis, a sor maradéka kimarad.

NEW
10 A = 5
20 IF A > 3 THEN PRINT "NAGYOBB"
30 IF A > 100 THEN PRINT "EZ NEM LATSZIK"
RUN
NAGYOBB
Ok

Szöveggel is

NEW
10 V$ = "IGEN"
20 IF V$ = "IGEN" THEN PRINT "RENDBEN"
30 IF V$ <> "NEM" THEN PRINT "TENYLEG"
RUN
RENDBEN
TENYLEG
Ok

Összehasonlítani lehet = <> < > <= >= jelekkel. Szövegnél a sorrend ábécé szerinti.

Ugrás

Ha a THEN után puszta szám áll, az ugrást jelent — ez korhű rövidítés a GOTO-ra:

NEW
10 A = 1
20 PRINT A
30 A = A + 1
40 IF A < 4 THEN 20
50 PRINT "VEGE"
RUN
 1
 2
 3
VEGE
Ok
Végtelen ciklus

Egy 10 GOTO 10 sosem állna meg.

A gép 200 000 utasítás után magától megáll, és kiírja: TOO MANY STATEMENTS - STOPPED. A ^C bármikor megszakítja a futást.

◉

Ismétlés

A FOR … NEXT megszámolja, hányszor fusson le valami.

NEW
10 FOR I = 1 TO 5
20 PRINT I;
30 NEXT I
RUN
 1  2  3  4  5 Ok

A 20 PRINT I; sorvégi pontosvesszője miatt marad minden egy sorban.

Lépésköz

NEW
10 FOR I = 10 TO 1 STEP -3
20 PRINT I;
30 NEXT I
RUN
 10  7  4  1 Ok

A STEP lehet negatív is — akkor visszafelé számol.

Egymásba ágyazva

NEW
10 FOR S = 1 TO 3
20 FOR O = 1 TO 3
30 PRINT S*O;
40 NEXT O
50 PRINT
60 NEXT S
RUN
 1  2  3
 2  4  6
 3  6  9
Ok
A NEXT megnevezheti a változót

A NEXT O

alak kimondja, melyik ciklust zárja. Nem kötelező, de hosszú programban ez menti meg az embert. Egyszerre 8 ciklus lehet nyitva.

A ciklus belépéskor is vizsgál

Egy FOR I=1 TO 0

egyszer sem fut le. A gép átugrik a NEXT utánra.

◉

Alprogramok

A GOSUB elugrik egy sorra, és a RETURN visszahozza oda, ahonnan jött. Ettől lesz egy program olvasható.

NEW
10 PRINT "ELOTTE"
20 GOSUB 100
30 PRINT "UTANA"
40 END
100 PRINT "  AZ ALPROGRAMBAN"
110 RETURN
RUN
ELOTTE
  AZ ALPROGRAMBAN
UTANA
Ok
Az END nem dísz

A 40 END nélkül a

program „belesétálna" az alprogramba, és a RETURN panaszkodna: RETURN WITHOUT GOSUB. Az alprogramokat mindig a program vége után tedd.

Egyszerre 12 GOSUB lehet nyitva.

Kérdezés

Az INPUT megállítja a programot, és megvárja, amíg beírsz valamit. Ettől lesz a programból beszélgetés.

NEW

20 PRINT "TIZ EV MULVA "; K + 10
RUN

Ok

A kérdés után a gép kiteszi a ? jelet. Ha nem kérsz kérdést, csak a kérdőjel jelenik meg:

A program nem áll le

Ha számot kér és betűt kap, a gép kiírja:

?REDO FROM START — és újra kérdez. A korabeli gépek pontosan így viselkedtek.

A vessző idézőjelek között

Ha a válaszodban kell a

vessző, tedd idézőjelbe: "KOVACS, JANOS". Az üres válasz (csak Enter) számnál 0, szövegnél üres szöveg.

Csak programból

Az INPUT sorszám nélkül nem

használható — ILLEGAL DIRECT. Ez korhű: nincs értelme megkérdezni valamit, ha nincs program, ami felhasználná.

A lemez a DOS felől

Itt derül ki, miért érdemes egy BASIC-nek olyan gépen laknia, amelyiknek van DOS-a.

A BBASIC a programot sima szövegként menti — nem tömörítve. Vagyis a DOS minden fájlkezelő parancsa érti a BASIC-programodat. Mentsünk el egyet, lépjünk ki, és nézzük meg a parancssorból:

BBASIC
BAROQUE BASIC 1.1
49152 BYTES FREE
Ok
NEW
10 PRINT "A LEMEZEN SZOVEG VAGYOK"
20 PRINT "A DOS TYPE-ja elolvas"
SAVE "OLVASD"
SAVED OLVASD.BAS  2 LINES  70 BYTES
Ok
SYSTEM
C:\>
TYPE OLVASD.BAS
10 PRINT "A LEMEZEN SZOVEG VAGYOK"
20 PRINT "A DOS TYPE-ja elolvas"
C:\>

A DIR is látja, méretestül:

DIR *.BAS

OLVASD   BAS         70  02-01-80  02:23
        1 FILE(S)           70 BYTES

C:\>
Amit ez megnyit

A COPY CON JATEK.BAS paranccsal

szövegszerkesztő nélkül írhatsz BASIC-programot. A COPY másolja, a REN átnevezi, a CHKDSK számolja. Egy program ugyanolyan fájl, mint bármi más.

Eltérés a korabelitől

A GW-BASIC alapból tömörítve

mentett, és csak a SAVE "X",A adott szöveget. Nálunk mindig szöveg van. Ez szándékos: egy pár bájt megtakarításnál többet ér, hogy a DOS is olvassa.
